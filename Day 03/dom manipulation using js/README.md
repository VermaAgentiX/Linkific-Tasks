# Linkific Day 3 — JavaScript and Python practice

## Website
Open `index.html` in a browser, or use VS Code Live Server. It demonstrates:
- DOM manipulation (`getElementById`, `textContent`, `createElement`, `appendChild`)
- Events with `addEventListener`
- `let`, `const`, arrays, objects, functions and responsive navigation
- Factorial, Fibonacci, duplicate detection and a clickable task checklist

## Python programs
Run from the project folder:
```bash
python python/factorial.py
python python/fibonacci.py
python python/find_duplicates.py
python python/variables_demo.py
```

## Expected examples
- factorial(5) -> 120
- fibonacci(8) -> 0, 1, 1, 2, 3, 5, 8, 13
- duplicates in [1, 2, 3, 2, 4, 5, 1] -> [2, 1]
