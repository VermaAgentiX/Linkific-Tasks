# DevSpace — Linkific Day 3 Practice

A responsive, beginner-friendly page for practising JavaScript fundamentals and DOM manipulation.

## What's included
- Clean HTML structure with semantic sections and accessible labels
- Responsive CSS layout for desktop and mobile
- JavaScript event handling and DOM updates
- Dynamic note creation and a clickable task checklist
- Factorial calculator, Fibonacci generator, and duplicate finder
- `let` and `const` demonstration

## Run the project
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or run it with the Live Server extension.
4. Try each demo. For the variables example, open Developer Tools → Console.

## Example results
- Factorial of 5: `120`
- First 8 Fibonacci terms: `0, 1, 1, 2, 3, 5, 8, 13`
- Duplicates in `[1, 2, 3, 2, 4, 5, 1]`: `2, 1`
