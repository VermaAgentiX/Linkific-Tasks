# DevSpace — Responsive Landing Page

A responsive landing page built for HTML/CSS Day 2 practice. DevSpace is a fictional workspace concept for developers.

## Features
- Semantic HTML5 structure
- Responsive layouts for mobile, tablet, and desktop
- Flexbox navigation and alignment
- CSS Grid feature and project cards
- CSS variables and reusable styles
- Responsive typography with `clamp()`
- Mobile navigation menu using vanilla JavaScript
- Keyboard focus styles and reduced-motion support
- No external framework or build step required

## Technologies
HTML5, CSS3, vanilla JavaScript, Git, and GitHub.

## Project structure
```text
responsive-landing-page/
├── index.html

└── README.md
```

## Run locally
1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Alternatively, open the folder in VS Code and use Live Server if installed.

## Test responsiveness
Use browser Developer Tools to test widths such as 320px, 375px, 768px, 1024px, and 1440px. Check for horizontal scrolling, clipped content, readable text, and mobile menu behavior.

## Customize before publishing
- Change the colors in `:root` in `css/style.css`.
- Edit content in `index.html`.
- Replace `hello@example.com` with your actual contact destination.
- Update branding and add screenshots of your own running project.

## Learning outcomes
This project demonstrates semantic HTML, CSS selectors, the box model, Flexbox, Grid, media queries, responsive design, and basic DOM event handling.

**Note:** DevSpace is a fictional demo brand for practice and portfolio use.
