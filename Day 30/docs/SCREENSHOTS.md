# Screenshot Evidence Guide

The `screenshots/` directory is reserved for genuine screenshots captured from the running application. No screenshots are fabricated or represented as captured evidence in this archive.

Recommended captures:

1. `01-dashboard.png` — Overview page with sample/demo data.
2. `02-transactions.png` — Transaction table showing search and filters.
3. `03-transaction-form.png` — Create or edit transaction form.
4. `04-budgets.png` — Budget list and utilization view.
5. `05-customers-suppliers.png` — Contact management page.
6. `06-api-swagger.png` — FastAPI Swagger UI at `/docs`.

Capture steps:

1. Start the backend and frontend using the README instructions.
2. Add clearly fictional demo records; do not use real customer or bank data.
3. Resize the browser to a clean desktop viewport and capture each relevant page.
4. Save PNG files in this folder using the filenames above.
5. If a page is incomplete or unavailable, do not create a misleading screenshot for it.

On Windows, use `Win + Shift + S` to capture a selected area. Keep browser chrome and personal information out of the screenshots where possible.
